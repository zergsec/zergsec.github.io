## 为什么开这个博客

学东西的时候总是「当时懂了，过两个月全忘」。把过程写下来，一来逼自己把逻辑理清楚，二来以后再遇到同样的问题能直接翻自己的笔记。

所以这里主要放三类内容：

1. **学习笔记** —— 读到的东西用自己的话重写一遍。
2. **踩坑记录** —— 报错信息、排查过程、最后怎么解决的。
3. **折腾日志** —— 工具、环境、配置这些琐碎但有用的东西。

## 这个站怎么搭的

用的是 [Hugo](https://gohugo.io/) + [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题，托管在 GitHub Pages 上：

| 环节 | 用的东西 |
| --- | --- |
| 生成器 | Hugo（extended 版） |
| 主题 | PaperMod |
| 托管 | GitHub Pages |
| 部署 | GitHub Actions，推送到 `main` 分支自动构建 |

整个流程是：本地写完 Markdown，`git push`，GitHub 那边自动编译成静态页面发布。本地不需要装任何服务端环境。

## 怎么找到想要的内容

- 顶部 **文章** 是全部文章列表；
- **归档** 按时间排；
- **标签** 按主题聚类；
- **搜索** 是模糊匹配，按 `Alt + /` 可以快速唤起。

如果哪篇笔记帮到你了，说明写它是有意义的。
